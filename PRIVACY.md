# Privacy Policy

This privacy policy explains what data Tab Manager Plus collects, how we use it, and your rights.

## Data Collection

Tab Manager Plus collects the following data to function:

- **Tab information**: URLs, titles, favicons, and tab states (pinned, muted, discarded). This is necessary to display and manage your tabs.
- **Window information**: Window positions, states (minimized/normal), and titles. This is necessary to organize windows.
- **Session data**: Saved tab arrangements. Stored locally on your device via browser storage.
- **Auto-backup data**: Automatic snapshots of your tab layout (optional). Stored locally via browser storage.
- **User preferences**: Layout, theme, colors, tab limits. Stored locally via browser storage.

## Data Usage

All collected data is processed locally within your browser extension. **No data is transmitted to external servers.**

## Data Storage

All data is stored in your browser's local extension storage (`browser.storage.local`). It is not backed up to cloud services and is tied to the browser profile where the extension is installed.

## Cookies & Tracking

Tab Manager Plus does not use cookies, tracking pixels, or analytics. No third-party scripts are loaded.

## Your Rights

You can:
- Export your session data at any time
- Delete all stored data by removing the extension
- Disable automatic backups in settings

## Contact

For questions about this extension, please open an issue on the GitHub repository.
